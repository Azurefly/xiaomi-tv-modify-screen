# 小米电视非官方投屏

专为小米电视做的 DLNA 投屏接收端。在电视上打开本应用，再在手机或平板的视频 App 里点 TV / 投屏，选择“小米电视非官方投屏”即可播放。

> ⚠️ **说明**：小米电视适配、安全加固和性能优化（0.1.7-test、0.1.8-test）由 AI 助手 Claude（Anthropic）完成，**未经实际测试**，待主播后续在小米电视上测试验证。

本项目与小米公司无关，不是小米官方产品。

## 针对小米电视的优化

小米电视（PatchWall 系统）大多使用联发科芯片、1.5–2 GB 内存，4K 机型的界面通常运行在 1080p。本应用据此做了以下调整：

- **解码器回退**：第一个硬件解码器初始化失败时，自动换下一个，减少 HEVC 或高码率片源直接报错。
- **按内存控制缓冲**：缓冲上限为可用内存的 1/4（24–96 MB，低内存机型固定 24 MB），避免 4K 片源导致内存溢出。
- **4K 自动画质**：界面是 1080p 的 4K 电视，“自动”模式也能选到 2160p 片源。
- **与系统投屏共存**：如果小米自带投屏占用了设备发现端口，改为每 30 秒主动广播一次，不会直接启动失败。
- **授权页兜底**：找不到标准的“显示在其他应用上层”授权页时，依次尝试 MIUI 权限页和应用详情页。
- **开机待机**（可选，默认关闭）：在等待页打开“开机待机”，电视冷启动后自动进入后台待机。
- **遥控器菜单键**：播放中按菜单键直接打开“清晰度”。

## 安装

1. 在 [Releases](https://github.com/Azurefly/xiaomi-tv-modify-screen/releases) 下载最新的 APK，用附带的 `SHA256SUMS.txt` 核对校验值。
2. 把 APK 拷到 U 盘，插到小米电视上，用文件管理或“高清播放器”打开安装。如提示禁止安装，在系统设置的安全选项中允许安装未知来源应用。
3. 打开“小米电视非官方投屏”，确认页面上显示了电视的局域网地址。

最低支持 Android 6.0。如果装过本应用的其他来源版本，签名不同，需要先卸载旧版。

## 使用

- 手机 / 平板和电视连接同一个家庭网络，在视频 App 里点投屏，选择“小米电视非官方投屏”。
- 播放时按方向键唤出操作栏，约 2 秒无操作自动收起；按菜单键打开“清晰度”；按返回键结束本次播放。
- 按 Home 回到桌面后仍可接收投屏。在“后台待机”里允许“显示在其他应用上层”后，收到新投屏会自动打开播放界面；未授权时需要手动打开本应用。
- 在应用里或通知中选择“退出接收”才会停止服务。

## 小米电视常见问题

**手机上搜不到本机**
- 先打开一次本应用，确认服务已启动。
- 在系统设置里临时关闭电视自带的投屏功能，再重新搜索。
- 检查手机是否连在访客网络，或路由器是否开启了 AP 隔离。

**回到桌面后过一会儿就收不到投屏**
- 小米电视的内存清理可能会关掉后台应用。在系统的应用管理 / 自启动管理里允许本应用自启动，并避免对它执行“一键清理”。
- 用遥控器关机通常只是进入待机，唤醒后服务一般仍在运行；完全断电重启后，需要开启“开机待机”或手动打开本应用。

**收到地址但不能播放**
- 打开“连接详情”查看错误代码。地址过期时，在手机端重新投屏即可。

## 限制

- 只支持 DLNA 投屏，不支持 AirPlay、Miracast、屏幕镜像和小米私有投屏协议。
- 不支持 DRM 加密内容，也不支持需要电视端登录或额外请求头的视频。
- 同一局域网内的任何设备都可以向电视投屏，请只在可信的家庭网络中使用，不要把接收端口映射到公网。

## 从源码构建

需要 JDK 17 或 21、Android SDK Platform 36 和 Build Tools 35.0.0。设置 `JAVA_HOME` 和 `ANDROID_HOME` 后执行：

```sh
bash build-local.sh
```

安装用的是 `app/build/outputs/apk/release/app-release.apk`（不可调试，经 R8 压缩优化）；`debug` 目录下的调试包仅供开发。构建脚本会自动生成本地测试签名，仓库不包含任何签名私钥。

没有 Android SDK 时，可以先跑一遍精简校验：

```sh
bash tools/verify-offline.sh
```

它不装 SDK，只下载约 55 MB 的 `android.jar`、`aapt2`、依赖 jar 和 `d8`，用来判定「改动能不能编过」——资源编译与链接、Java 类型检查、minSdk 23 字节码打包。lint、R8 压缩和真机行为不在覆盖范围内。
